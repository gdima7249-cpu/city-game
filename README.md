# City Game

Игра в открытом городе от третьего лица на движке Godot 4.
Готово:
- **этап 1**: персонаж бегает и прыгает по тестовой карте, камера управляется мышью;
- **этап 2**: машина, в которую можно сесть, поехать и выйти; от ударов на корпусе остаются вмятины;
- **этап 3** (в работе): квартал с дорогами, светофорами, машинами и пешеходами. Пока из домов-заглушек,
  модели Quaternius «Downtown City MegaKit» подключим следующим шагом.

## Как запустить на ПК

1. Скачайте Godot 4.7 или новее с официального сайта: https://godotengine.org/download
   Берите обычную версию (**Godot Engine**), а не «.NET». Godot не требует установки:
   это один файл в архиве. Распакуйте архив в любую папку.
2. Скачайте проект: на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**
   и распакуйте архив. (Или клонируйте репозиторий через GitHub Desktop.)
3. Запустите Godot. В окне «Менеджер проектов» нажмите **Импорт**, выберите файл
   `project.godot` из папки проекта и нажмите **Импорт и редактировать**.
   Если Godot предупредит, что проект сделан в другой версии, согласитесь на открытие.
4. Когда откроется редактор, нажмите **F5** (или треугольник ▶ справа сверху).

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D или стрелки | Идти |
| Shift | Бежать |
| Пробел | Прыжок (короткое нажатие — прыжок пониже) |
| Мышь | Камера |
| Колесо мыши | Приблизить / отдалить камеру |
| Esc | Показать курсор; клик мышью вернёт управление |

| E | Сесть в машину (подойдите вплотную) / выйти |

### В машине

| Клавиша | Действие |
| --- | --- |
| W | Газ |
| S | Тормоз, после остановки — задний ход |
| A / D | Руль |
| Пробел | Ручник (занос) |
| R | Поставить перевёрнутую машину на колёса |
| Мышь | Осмотреться; через пару секунд камера сама встанет сзади |
| E | Выйти (когда машина почти стоит) |

Управление работает и при русской раскладке клавиатуры.

## Что есть на тестовой карте

- Ящики разной высоты, чтобы проверить прыжок.
- Пандус на возвышение.
- Стены и узкий коридор с крышей: камера не должна проходить сквозь них.
- Цепочка платформ для прыжков.
- Высокие коробки на месте будущих небоскрёбов.
- Красная машина рядом с местом старта и штабель ящиков на дороге, чтобы в него врезаться.
- Квартал: езжайте или идите по дороге прямо от старта (на север). Там 12 кварталов с домами,
  светофоры на каждом перекрёстке, около 26 машин и 45 пешеходов.

Все модели временные: простые фигуры-заглушки. Настоящие модели подключим позже,
каждый пак — только после вашего одобрения.

## Как настроить управление под себя

Откройте сцену `scenes/player.tscn`, выберите узел **Player** и в панели **Инспектор**
справа меняйте числа: скорость шага и бега, силу прыжка, чувствительность мыши.

Машина настраивается так же: сцена `scenes/car.tscn`, узел **Car** (мощность, тормоза,
руль, ручник, сила вмятин). Подвеска и сцепление шин настраиваются на каждом колесе
(узлы `Wheel...`).

## Структура

```
project.godot          настройки проекта
scenes/main.tscn       тестовая карта
scenes/player.tscn     персонаж и камера
scripts/player.gd      движение, прыжок, камера
scenes/car.tscn        машина
scripts/car.gd         езда, вход и выход, камера машины, удары
scripts/deformable_mesh.gd  вмятины на корпусе
scripts/input_setup.gd назначение клавиш и курсор мыши
scripts/city/          квартал: сетка дорог, светофоры, машины трафика, пешеходы
```

## Как устроен квартал

Узел **District** в `scenes/main.tscn` строит квартал кодом при запуске (`scripts/city/city_grid.gd`).
В инспекторе можно поменять число кварталов, их размер, количество машин и пешеходов.

- Светофор даёт зелёный по очереди каждому въезду на перекрёсток. Так машины не пересекаются
  внутри перекрёстка и трафик не может намертво застрять.
- Машины едут по правой полосе, держат дистанцию, тормозят перед игроком и его машиной.
- Пешеходы гуляют по тротуарам вокруг кварталов и обходят игрока стороной (ждут, пока он отойдёт).

Пока упрощено: машины трафика и пешеходы не реагируют на аварии, а машина игрока проезжает
сквозь пешеходов. Реакции жителей появятся на следующих этапах.
