# City Game

Игра в открытом городе от третьего лица на движке Godot 4.
Сейчас готов **этап 1**: персонаж бегает и прыгает по тестовой карте, камера управляется мышью.

## Как запустить на ПК

1. Скачайте Godot 4.7 или новее с официального сайта: https://godotengine.org/download
   Берите обычную версию (**Godot Engine**), а не «.NET». Godot не требует установки:
   это один файл в архиве. Распакуйте архив в любую папку.
2. Скачайте проект: на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**
   и распакуйте архив. (Или клонируйте репозиторий через GitHub Desktop.)
3. Запустите Godot. В окне «Менеджер проектов» нажмите **Импорт**, выберите файл
   `project.godot` из папки проекта и нажмите **Импорт и редактировать**.
   Если Godot предупредит, что проект сделан в другой версии, согласитесь на открытие.
4. Когда откроется редактор, нажмите **F5** (или треугольник ▶ справа сверху).

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D или стрелки | Идти |
| Shift | Бежать |
| Пробел | Прыжок (короткое нажатие — прыжок пониже) |
| Мышь | Камера |
| Колесо мыши | Приблизить / отдалить камеру |
| Esc | Показать курсор; клик мышью вернёт управление |

Управление работает и при русской раскладке клавиатуры.

## Что есть на тестовой карте

- Ящики разной высоты, чтобы проверить прыжок.
- Пандус на возвышение.
- Стены и узкий коридор с крышей: камера не должна проходить сквозь них.
- Цепочка платформ для прыжков.
- Высокие коробки на месте будущих небоскрёбов.

Все модели временные: простые фигуры-заглушки. Настоящие модели подключим позже,
каждый пак — только после вашего одобрения.

## Как настроить управление под себя

Откройте сцену `scenes/player.tscn`, выберите узел **Player** и в панели **Инспектор**
справа меняйте числа: скорость шага и бега, силу прыжка, чувствительность мыши.

## Структура

```
project.godot          настройки проекта
scenes/main.tscn       тестовая карта
scenes/player.tscn     персонаж и камера
scripts/player.gd      движение, прыжок, камера
scripts/input_setup.gd назначение клавиш
```
